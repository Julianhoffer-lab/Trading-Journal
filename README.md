# 📈 Trading Journal (PWA)

## 🇬🇧 English

A modern, full-stack Trading Journal Progressive Web App (PWA) designed to log, analyze, and track trading performance, equity curves, and strategy metrics.

### 🌟 Features

*   **Trade Management:** Log and manage trades with entry/exit prices, position sizes, stop-loss, take-profit, and automatic R-Multiple calculations.
*   **Trade Details Modal:** Interactive modal to review and update individual trade notes and setup details.
*   **Lightbox Screenshot Preview:** Attach and view chart screenshots directly inside the trade modal.
*   **Analytics & Charts:** Interactive equity curves and metrics visualization powered by Recharts.
*   **Dark & Light Mode:** Seamless theme switching with Tailwind CSS.
*   **Installable PWA:** Works as a desktop/mobile app with offline support capabilities.

### 🛠️ Tech Stack

*   **Frontend:** React 19, Vite 8, Tailwind CSS, Recharts, Lucide Icons, `vite-plugin-pwa`
*   **Backend:** Java, Spring Boot 3, REST API
*   **Database & Migration:** PostgreSQL 16, Flyway
*   **DevOps:** Docker & Docker Compose

### 🚀 Getting Started with Docker

#### Prerequisites
*   Docker Desktop installed and running.

#### Run the Application
1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/trading-journal.git
   cd trading-journal
   ```

2. **Build and start all services via Docker Compose:**
   ```bash
   docker compose up -d --build
   ```

3. **Open your browser and navigate to:**
   *   **Frontend / PWA:** [http://localhost:5173](http://localhost:5173)
   *   **Backend API:** [http://localhost:8081](http://localhost:8081)

## 🇩🇪 Deutsch

Ein modernes Full-Stack Trading Journal als Progressive Web App (PWA) zum Erfassen, Analysieren und Auswerten von Trades, Equity-Kurven und Strategie-Kennzahlen.

### 🌟 Funktionen

*   **Trade-Verwaltung:** Erfassen von Trades mit Entry/Exit-Preisen, Positionsgrößen, Stop-Loss, Take-Profit und automatischer R-Multiple-Berechnung.
*   **TradeDetails-Modal:** Übersichtliches Fenster zum Bearbeiten von Trades und Notizen.
*   **Lightbox-Vorschau:** Upload und direkte Großansicht von Chart-Screenshots.
*   **Analysen & Charts:** Interaktive Performance-Auswertungen mit Recharts.
*   **Dark & Light Mode:** Flexible Design-Umschaltung via Tailwind CSS.
*   **Installierbare PWA:** Kann als eigenständige Desktop- oder Smartphone-App installiert werden.

### 🛠️ Technologiestack

*   **Frontend:** React 19, Vite 8, Tailwind CSS, Recharts, Lucide Icons, `vite-plugin-pwa`
*   **Backend:** Java, Spring Boot 3, REST API
*   **Datenbank & Migration:** PostgreSQL 16, Flyway
*   **DevOps & Container:** Docker & Docker Compose

### 🚀 Schnellstart mit Docker

#### Voraussetzungen
*   Docker Desktop muss installiert sein und laufen.
